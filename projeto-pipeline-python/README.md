# Pipeline completa stack Python

A ideia deste laboratório é praticar os conhecimentos adquiridos durantes o curso de GitHub Actions.

```text
                    CI Pipeline
                        │
        ┌───────────────┼────────────────┐
        │               │                │
   Code Quality      Testing          Security
        │               │                │
   ┌────┼────┐      ┌───┴────┐       ┌───┴────┐
   │    │    │      │        │       │        │
 Black isort Flake8 pytest pytest-cov Safety Bandit
                              │
                           Codecov
```

No final, teremos uma execução elegante e performática do workflow, similar ao que acontece no mercado e no mundo real de devops (principalmente se tratando de **Quality Gate**).

Estrutura da pipeline:

```text
Code Quality
     ↓
Unit Tests
     ↓
Security Scan
     ↓
Docker Build
     ↓
Integration Tests
     ↓
Performance Tests
     ↓
Deploy
```

## Objetivo

Criar conta no Docker Hub, gerar token de acesso e configurar secrets no GitHub Actions.


## O que você vai precisar

- Conta Docker Hub
- Token de acesso Docker Hub
- GitHub Secrets (DOCKERHUB_USERNAME e DOCKERHUB_TOKEN)

## Stack de ferramentas utilizadas para a análise e qualidade de código

| Tool | Documentation | Usage |
|---|---|---|
| **Black** | [Documentation](https://black.readthedocs.io/) | Python code formatter. Used to enforce a consistent code style automatically. |
| **isort** | [Documentation](https://pycqa.github.io/isort/) | Python import sorter. Used to organize and standardize imports across the project. |
| **Flake8** | [Documentation](https://flake8.pycqa.org/) | Python linter. Used to detect syntax errors, undefined names, and code quality issues. |
| **pytest** | [Documentation](https://docs.pytest.org/) | Python testing framework. Used to implement and execute unit and integration tests. |
| **pytest-cov** | [Documentation](https://pytest-cov.readthedocs.io/) | Pytest coverage plugin. Used to measure test coverage and generate coverage reports. |
| **Codecov** | [Documentation](https://docs.codecov.com/) | Code coverage reporting platform. Used to upload and visualize test coverage generated by the CI pipeline. |
| **Safety** | [Documentation](https://docs.safetycli.com/) | Python dependency security scanner. Used to identify known vulnerabilities in project dependencies. |
| **Bandit** | [Documentation](https://bandit.readthedocs.io/) | Python security linter. Used to detect common security issues in Python source code. |
| **Locust** | [Documentation](https://docs.locust.io/) | Load testing framework. Used to simulate concurrent users and evaluate API performance. |
